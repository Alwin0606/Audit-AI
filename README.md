## 🚀 Overview

**Audit AI** is an intelligent security auditing platform designed to simplify security assessments, identify potential risks, and support automated analysis through AI and data-driven techniques.

The platform aims to help organizations improve their security posture by transforming audit data into meaningful insights, identifying suspicious patterns, and presenting findings through an intuitive interface.

Built using Python and Flask, Audit AI provides a foundation for intelligent security auditing, risk analysis, and automated reporting.

## ✨ Key Features

- 🛡️ **Security Auditing** – Analyze audit data and identify potential security concerns.
- 🤖 **AI-Powered Analysis** – Apply intelligent analysis techniques to security-related information.
- 🔍 **Risk Detection** – Identify potentially suspicious activities and anomalies.
- 📊 **Security Dashboard** – Monitor audit findings and security insights.
- 📁 **CSV Data Analysis** – Process structured audit datasets.
- 🚨 **Anomaly Detection** – Highlight unusual patterns in analyzed data.
- 📑 **Audit Reporting** – Organize findings for security review.
- ⚡ **Automated Processing** – Simplify repetitive auditing workflows.
- 🎨 **Modern Interface** – Access security insights through a clean dashboard.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Alwin0606/Audit-AI.git
```

### 2. Navigate to the Project

```bash
cd "Audit AI"
```

### 3. Create a Virtual Environment

```bash
py -3.13 -m venv .venv
```

### 4. Activate Virtual Environment

**Windows PowerShell:**

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

Open your browser:

```text
http://127.0.0.1:5000
```
